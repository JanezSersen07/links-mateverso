# Links de Mateverso
![Vista de la página](captura.PNG)


Página de links para el emprendimiento **Mateverso**: un solo lugar con acceso a la tienda online, WhatsApp y redes sociales. Pensada para abrirse desde el celular, que es donde la ven los clientes desde Instagram y TikTok.

🔗 **Ver online:** https://janezsersen07.github.io/links-mateverso/

## Qué incluye

- Botones a la tienda online (Tienda Nube), WhatsApp, Instagram y TikTok.
- Diseño adaptable (responsive), con los colores de la marca definidos en un solo lugar.
- Efectos suaves al pasar el cursor o tocar un botón.
- Sin librerías externas: solo HTML y CSS.

## Tecnologías

HTML5, CSS3 (variables CSS, flexbox) y GitHub Pages para publicarla.

## Estructura

```
links-mateverso/
├── index.html   # contenido de la página
├── style.css    # estilos y colores de la marca
└── (logo)       # imagen del logo de Mateverso
```

## Cómo verla en tu compu

1. Descargá o cloná el repositorio.
2. Abrí `index.html` en el navegador.

## Qué aprendí

Maquetar con HTML semántico, centrar y distribuir elementos con flexbox, usar variables CSS para mantener los colores en un solo lugar y publicar una página gratis con GitHub Pages.
